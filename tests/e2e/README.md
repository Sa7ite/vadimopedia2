# Проверки в браузере (Playwright)

Скрипты, которыми агент проверяет сайт. Хранятся в репозитории, чтобы не пропали при сбросе песочницы.

**Как запустить (песочница агента):**
1. Репозиторий лежит в `/data/repo`, скрипты копируются в `/data/tests/` (они ссылаются на `/data/tests/lib.mjs` и `/data/repo/js/config.js`).
2. Пароль тестовых аккаунтов — в файле `/data/.testpw` (в репозиторий не кладётся; если пропал — сбросить пароль `agent-admin@vadimopedia.test` и `agent-user@vadimopedia.test` через Supabase и записать заново).
3. Локальный сервер: `cd /data/repo && python3 -m http.server 8765`.
4. Запуск из `/data`: `node tests/smoke.mjs` (нужны `playwright-core` и Chromium `/usr/local/bin/chromium`).

| Файл | Что проверяет |
|---|---|
| `lib.mjs` | общие функции: вход тестовым аккаунтом, запуск браузера, переход по разделам, проверка прокрутки вбок |
| `smoke.mjs` | меню и разделы открываются, нет ошибок (старый вид) |
| `b390.mjs`, `chat390.mjs` | телефон 390 px |
| `mod214.mjs` | модерация, жалобы, журнал (T2.14) |
| `cases1.mjs`, `cases2.mjs` | дела, ордер, «К вам пришли», суд (T2.12) |
| `chat213.mjs` | чат: ответы, упоминания, реакции, мут (T2.13) |
| `bell215.mjs` | колокольчик и настройки уведомлений (T2.15) |
| `t31.mjs` | снимки всех разделов в новой теме (гость и админ, 1440 и 390) в `/data/work/t31/` |
| `t32.mjs` | главная-картотека и ящик «События» (T3.2) |
| `design-shots.mjs` | снимки блоков страницы вариантов `design/`: `node design-shots.mjs 13313133 1440` |
