# Вадимопедия

Шуточная энциклопедия обо всех Вадимах мира: события, летопись (пишет ИИ, проверяет админ), чат, теории, «Событие года», игровые дела, титулы, достижения, фракции.

**Сайт:** https://vadimopedia.vercel.app (новое оформление «Секретное досье», пока идёт Фаза 3: https://vadimopedia.vercel.app/?new=1)

## Документы
- [`docs/user-guide.md`](docs/user-guide.md) — **руководство пользователя** (обновляется вместе с сайтом).
- [`docs/handoff.md`](docs/handoff.md) — ТЗ и рабочий документ: механики, план задач, состояние, адреса сервисов (раздел 3.1), правила работы агента.
- [`docs/design.md`](docs/design.md) — дизайн-спецификация «Секретное досье», выбор владельца и ход работ (раздел 15).
- [`docs/quality-log.md`](docs/quality-log.md) — оценки критика по задачам.

## Устройство
- Фронтенд: HTML/CSS/JS без сборки, хостинг Vercel (публикуется из ветки `main`).
- База, вход, функции: Supabase (проект `dgfsxsargqypvwiifyrp`), миграции в `supabase/migrations/`.
- ИИ летописи: функция `supabase/functions/chronicle-ai` → OpenRouter (ключ в секрете Supabase `vadimopedia-AI-KEY`).

## Файлы
- `index.html` — разметка; оформление одно, «Секретное досье» (`data-theme="dossier"`).
- `dossier.css` — вся тема «Секретное досье» (токены, базовые правила, компоненты, экраны); `board.css` — доска расследования. Старые `style.css` и `themes.css` удалены в T3.10.
- `extras.js` — мелочи: поиск, «Поделиться», новая глава, «Событие дня», Esc, PWA; `sw.js`, `manifest.json` — установка как приложение.
- `js/config.js` — подключение к Supabase (публичный anon-ключ, это нормально); `js/api.js` — запросы к базе; `js/auth.js` — вход и регистрация.
- `js/main.js` — точка входа и обработчики; `js/ui.js` — отрисовка; `js/icons.js` — свои иконки.
- `js/desk.js` — главная-картотека; `js/bell.js` — уведомления; `js/cases.js` — дела; `js/moderation.js` — очередь и жалобы; `js/admin.js` — Канцелярия; `js/validation.js` — проверка дат и мест.
- `design/` — страница вариантов дизайна (`design/#v=13313133` — выбор владельца).
- `tests/` — тесты логики летописи; `tests/e2e/` — проверки в браузере.

В репозитории нет и не должно быть секретов: он публичный.
